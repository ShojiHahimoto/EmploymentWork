# 対戦ラウンド・決着演出仕様

## ラウンド開始と進行

- 対戦は同一バトルシーン内で進める。初回・次ラウンドとも開始前は両者の対戦操作と対戦タイマーを止める。
- 開始前の待ち時間、ラウンド名（第1ラウンドは `ROUND 1`、第2ラウンドは `ROUND 2`、第3ラウンドは `FINAL ROUND`）、表示間の待ち時間、`FIGHT`、操作解禁前の待ち時間の順。最後の待ち時間が終わってから操作とタイマーを開始する。
- HPが0になった時点で対戦操作を止め、長いヒットストップを開始する。通常は `K.O.`、同じフレームで両者のHPが0なら `DOUBLE K.O.` を表示する。K.O.表示が消えるフレームでヒットストップを解除する。
- 解除後は操作を止めたまま動きを再開し、K.O.された側が倒れる。ダブルK.O.では両者とも倒れ、勝利モーションは流さず、倒れたまま暗転する。
- 勝者がいる場合は所定の間を置いて勝利モーションを再生する。試合が続く場合は勝利モーション中、試合が決着した場合はWIN／DRAWの表示中の入力で暗転へ進む。K.O.表示中はスキップしない。
- 試合続行時は暗転中にHP、タイマー、位置、姿勢、対戦中の一時状態をリセットする。取得ポイントは保持し、両者が通常どおり立った状態で次ラウンドを開始する。

## 得点と試合決着

- 通常のK.O.は勝者に1ポイント、ダブルK.O.は両者に1ポイント。取得ラウンドマークに反映する。
- 時間切れは `TIME OVER` と表示し、残りHPの多い側に1ポイント、同値なら両者に1ポイントを付与する。
- 2ポイント先取で試合終了。単独で到達した場合は勝利モーションの開始と同時に `PLAYER 1 WIN` または `PLAYER 2 WIN` を表示する。K.O.で決まった場合はK.O.表示の後に出す。
- 両者が同時に2ポイントに達したら引き分け。ダブルK.O.で決まった場合は `DOUBLE K.O.` の後、勝利モーションと勝利表示の代わりに `DRAW` を表示する。ダブルK.O.でも単独で2ポイントに達した場合、両者のダウンは維持する。
- 最終ラウンドの演出と暗転の後は、別のリザルトシーンに遷移せず、同じバトルシーン内にリザルトメニューを表示する。

## リザルトメニュー

1. 再戦：キャラ、デバイス、キーコンを維持し、取得ポイントをゼロに戻して `ROUND 1` から始める。
2. キャラクター選択に戻る：デバイス割り当てを引き継ぎ、準備完了などの一時状態は解除する。その後に再戦せず、コントローラー選択やタイトルへ通常の戻り操作で進んでも破綻しないこと。
3. タイトルに戻る：タイトルシーンへ戻る。

## 演出時間の調整

- 同じ段階で出る表示は時間設定を共有する。K.O.／DOUBLE K.O.／TIME OVER は決着表示、WIN／DRAW は最終結果表示としてまとめる。
- 入場からROUND表示まで、FIGHT消去から操作解禁まで、HPが0になってから決着表示まで、解除から勝利モーション開始まで、勝利モーションの再生時間、ダブルK.O.後の暗転までの間、暗転時間も個別に調整する。
- 対戦の固定フレームを時間管理の基準にできる。秒で調整する場合は固定フレームに換算する。演出用の時計はヒットストップ中も進める。

## 実装順序

演出時間は `assets/BattleConfig/RoundTiming.json` を対戦への入場時に読み込む。すべて60fpsのフレーム数で、変更後は対戦へ入り直す。

| キー | 計測区間 |
| --- | --- |
| `roundIntroDelayFrames`, `roundDisplayFrames`, `roundToFightFrames` | 開幕までの間、ラウンド名の表示、FIGHTまでの間 |
| `fightDisplayFrames`, `fightToControlFrames` | FIGHTの表示、消去から操作解禁まで |
| `roundEndDisplayDelayFrames`, `roundEndDisplayFrames`, `roundEndAfterDisplayFrames` | K.O.／DOUBLE K.O.／TIME OVERの表示開始まで、表示中、消去後の間。K.O.時の停止は表示終了まで |
| `releaseToVictoryFrames`, `victoryMotionFrames` | 停止解除から勝利演出までの最短時間、試合が続く場合の勝利モーションの再生時間 |
| `doubleKnockoutDownFrames` | ダブルK.O.で停止解除から次の演出へ進むまでの最短時間 |
| `matchResultDisplayFrames` | WIN／DRAWの最大表示時間。時間満了か入力で暗転し、勝利モーションは画面遷移まで進める |
| `fadeOutFrames`, `fadeInFrames` | 決着後の暗転、次ラウンドで暗転から復帰する時間 |

1. **演出素材の書き出し**：`assets/texture/UI/Parts/Battle` に、`ROUND 1`、`ROUND 2`、`FINAL ROUND`、`FIGHT`、`K.O.`、`DOUBLE K.O.`、`TIME OVER`、`PLAYER 1 WIN`、`PLAYER 2 WIN`、`DRAW` の透過PNGを用意する。同じ書体・縁・陰影で、控えめな立体感を揃える。ラウンド名は文字と数字を一体で書き出す方針とし、別素材に分ける場合でも新規の数字は1と2のみ。既存のタイマー数字を無理に流用しない。実際の対戦画面に重ね、文字の見え方を確認する。
2. **ラウンド進行**：入力とタイマーの制御、決着判定、得点、取得マーク、次ラウンドのリセットを先に検証する。
3. **演出の接続**：文字素材とヒットストップ、ダウン・勝利モーション、スキップ、暗転をつなぐ。先に既存モーションの有無を確認し、演出ごとの時間調整と表示・解除の順序を検証する。
4. **同一シーン内リザルト**：3項目のメニューを追加し、再戦とタイトル復帰に加え、キャラクター選択からコントローラー選択やタイトルへ戻る経路まで確認する。
