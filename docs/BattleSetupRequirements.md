# バトルセットアップ専用UI 要件

## 画面イメージの補足
- BattleSetupDeviceConcept-v2.png：パネルは画面を埋めず、未決定アイコンの幅はパネル幅の約4分の1。控えめな落ち影と上辺の光沢で操作部品の厚みを出す。
- BattleSetupKeyConfigConcept-v2.png：選択キャラの枠線に1P・2Pタブを付ける。画像内のHUMAN表記は不要。キャラの技一覧は分類ごとにABXYを縦4行で並べる。

## 共通
- 既存のカスタマイズ画面とヘッダー、文字、ボタン、枠、余白の作りを揃える。色調のみ暗めにする。強い発光や金属装飾は不要。
- ヘッダーは「バトルセットアップ」。構成図の吹き出し、状態ラベル、下部の操作説明、操作デバイス表、「キャラクター詳細」見出しは表示しない。

## プレイヤー選択
- 左が1P、右が2P。キーボードと接続済みの全ゲームパッドを表示する。左右入力は入力元のアイコンだけを移動させる。
- 未決定の機器は選択中の枠の左上に小さく詰めて並べる。決定した枠には確定した機器だけを中央に表示する。他の機器は、反対側が空いていればそちらへ移す。
- 各側の決定状態と割り当て機器をデータとして保持し、描画はその状態を参照する。アイコン座標から決定状態を推定しない。
- 両側が決定すると対人戦のキャラクター選択へ。片側だけ決定した状態で、その側が改めて決定すると相手側をCPUとしてキャラクター選択へ進む。CPUの対戦AI追加は対象外。

## キャラクター選択
- 中央には作成済みキャラクターの名前を太字で最大横2列に並べ、一覧全体を縦中央に配置する。奇数なら最終段の1人を中央に置く。
- 左右に各側がフォーカスしているキャラクター名、地上技・空中技・必殺技を表示する。各行は既存のA/B/X/Yスロット印の直後に技名、未設定は「空」。技名末尾の /A 等は不要。
- キャラクターを決定した側だけキーコンフィグと準備完了を展開する。対人戦では各側を担当機器で操作し、準備完了中はキャンセルのみ受け付け、両側の準備完了で対戦へ。
- キーコンフィグは担当機器のデフォルト設定から開始。キーボードとパッドの設定は別枠とし、担当機器の既存の設定項目だけを表示する。
- キーコンフィグ欄で左右入力するとデフォルトとカスタム1〜3を切り替える。決定による編集はカスタムのみ。名前入力を設けない。旧方式のファイルは変更しない。
- 割り当てパネルは移動上・下・左・右と攻撃A・B・X・Yの縦8行。使用済みの入力は変更元と交換する。保存は該当する機器種別の固定枠に上書きし、キャンセルでは編集中の変更を破棄する。
- 1Pのタブは枠の左上、2Pは右上。同じキャラを選んだ場合は同じ枠に両方を残す。タブPNGは共用し、片側は背景だけ左右反転する。

## CPU戦の操作順
- 決定した側が人間、反対側がCPU。機器は人間が決定した側に残し、人間側のキャラクター選択から始める。準備完了後は同じ入力機器の操作先をCPU側へ移す。
- CPU側のキャラクター選択でキャンセルすると、人間側の準備完了を解除して同じ側の操作に戻る。プレイヤー選択画面までは戻らない。
- CPU側ではキャラクター決定後もキーコンフィグを表示しない。CPU側の準備完了で対戦へ進む。
