カスタマイズのコードを読む

画面を操作したとき、どのオブジェクトが何を受け取り、どのデータを書き換え、どう描画・保存されるのか。実コードを追って理解するための教材です。

最初に：この資料の読み方

01から順に読み、各章の実コードで処理を確認してください。わからない呼び出しは関数別ページへ移動できます。関数別ページには全文を掲載しています。コードを読まずに概要だけで全体を理解したことにはしません。

読み進める順序

  1. 入口から理解する：オブジェクトと責務

    Scene、Controller、View、データの違いを、実際の所有関係から説明します。

  2. 1フレームを追う：更新と描画の順序

    GameからScene、UI、プレビューまでの時間的な順序を理解します。

  3. 下書きとUIとJSON：データの置き場所

    同じ値が複数箇所に見える理由と、どれが保存対象なのかを理解します。

  4. 専用UI：クリックが処理になるまで

    Rootの登録方式、フォーカス、文字入力、描画キャッシュを読み解きます。

  5. 技編集：フレームと判定を読み解く

    発生・持続・硬直、硬直差、プレビューの1Fずれを数値例で理解します。

  6. モーション：キーから1フレームの姿勢へ

    Quaternion、補間、FK、バインド姿勢、スキニングの関係を理解します。

  7. IKと可動域：位置要求を回転に変換する

    平行移動の目標、固定長の骨、到達限界、制限の連続性を理解します。

  8. プレビュー：カメラ・Gizmo・描画

    座標系と編集対象を分け、プレビューが最終的なモデル表示になるまで追います。

  9. 保存・読込・プリセット：ファイルへ届く経路

    ID、表示名、JSON、キャッシュ、複数ファイル保存を区別します。

  10. Undo / Redo：1操作を記録する仕組み

    ボタンとドラッグを同じ履歴へまとめ、復元時に何を止めるか理解します。

  11. キャラクター作成と画面遷移

    技の作成と、既存技をキャラクターへ割り当てる処理の違いを理解します。

  12. 読解の確認とリファクタリングの順番

    理解したつもりを避ける確認問題と、変更を安全に進めるための具体的な観点です。

対象と対象外

カスタマイズのScene、全Customize Controller、専用UI、編集データ・保存読込、姿勢・IK・制限と、それを支える主要基盤を収録します。対戦ロジック全体やThirdPartyライブラリの全関数解説は対象外です。共通Rendererなどは全文を収録しますが、教材本文ではカスタマイズで使う経路を中心に説明します。

ファイル・関数索引 / 収録範囲と説明の深さを確認

掲載コードは生成時点の実物です。設計の理想像ではなく、現状の責務と副作用を説明しています。
