# カスタマイズのコードを読む

教材の入口は [index.html](index.html) です。ブラウザーで直接開けます。サーバーやインターネット接続は不要です。

以前の概要中心の3資料は、この教材へ置き換えました。

## 構成

1. 入口から理解する：オブジェクトと責務
2. 1フレームを追う：更新と描画の順序
3. 下書きとUIとJSON：データの置き場所
4. 専用UI：クリックが処理になるまで
5. 技編集：フレームと判定を読み解く
6. モーション：キーから1フレームの姿勢へ
7. IKと可動域：位置要求を回転に変換する
8. プレビュー：カメラ・Gizmo・描画
9. 保存・読込・プリセット：ファイルへ届く経路
10. Undo / Redo：1操作を記録する仕組み
11. キャラクター作成と画面遷移
12. 読解の確認とリファクタリングの順番

本文の図解・実コードから、[ファイル・関数索引](atlas.html) の個別解説へ移れます。
関数別ページには宣言、引数、戻り値、個別補足、条件分岐、return式、呼び出し先・呼び出し元の候補、実コードを掲載しています。
各ファイルの全文も収録し、メンバー変数、enum、struct、定数、補助定義を省略していません。

## 説明の範囲

中心はカスタマイズのScene、Customize Controller全体、専用UI、編集データ、保存読込、姿勢・IKです。
共通基盤も収録しますが、対戦処理全体とThirdPartyの内部全関数は対象外です。

本文と個別補足は手作業の説明です。関数契約の説明には現行ヘッダーのsummary/param/returnsも使用しています。
全関数に同じ深さの手作業解説があるわけではありません。深さと対象件数は [収録範囲](coverage.html) に記載しています。
関数索引と呼び出し候補は字句解析によるもので、C++コンパイラーの意味解析ではありません。
同名関数の候補は、所有クラスと引数で区別してください。

## 再生成・検証

プロジェクトのルートで実行します。

```powershell
node tools/BuildCustomizeBook.mjs
node tools/VerifyCustomizeBook.mjs
```

- `tools/CustomizeBookContent.mjs`：本文、ファイルの役割、関数の個別補足。
- `tools/BuildCustomizeBook.mjs`：実ソースの取り込みとHTML生成。
- `tools/VerifyCustomizeBook.mjs`：リンクと説明の有無の検査。
- `inventory.json`：ファイルのハッシュと関数定義一覧。
- `verification.json`：実施した資料検証の結果。
- `qa/`：ブラウザー表示確認用の画像。

ブラウザー検証にはPlaywrightとEdgeを使用します。`BOOK_NODE_MODULES`にPlaywrightを含むnode_modulesを指定して、検証コマンドへ`--browser`を付けます。

生成し直しても、手作業の解説が自動的に正しく更新されるわけではありません。コード変更時には本文も確認してください。
この資料の作成に伴うゲームソースの変更やゲーム実動作の検証は行っていません。
