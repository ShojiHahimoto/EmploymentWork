# Player_01 の造形基準

細部造形の基準は「プレイヤーモデルイメージ.png」の三面図（このフォルダーの [Turnaround.png](Turnaround.png)）。「タイトル画面完成形イメージ2.png」は構えとゲーム画面での見え方の基準とする。その後に実画面で了承された胴体の厚み・頭部の輪郭を巻き戻さない。照明付きの図をUVに投影して完成としない。

## 骨を先に固定する

指定された２枚目のファイル assets/model/TitleMannequin/TitleMannequin.fbx を原本として別ファイルで作業する。取り込み直後に既存モーションで肩・肘・股・膝の位置を確認。画像のAポーズに合わせてバインド姿勢を変更しない。書き出し前後で骨名、親子、ローカル静止行列、ルートの軸・単位、逆バインド行列を同一座標系に換算して比較する。末端骨を自動追加しない。

## モデリングで決める断面

- 顔：額は広い凸面、頬から顎先に向けて絞る。側面の黒い切り返しは面の折れに沿わせる。
- 胴：肩幅だけ広げず、側面からも胸板が腹より前に出るようにする。肩殻は上腕を覆うが脇を塞がない。腹部は細い一本の軸でなく、胸郭と骨盤をつなぐ厚い可動部。
- 腕と脚：前腕は肘側に量感を残し手首で絞る。大腿前面の張りとふくらはぎ後面の張りを別の高さに置く。膝前の盾形装甲、後方の屈曲空間、踵からつま先までの接地面を側面で確認する。
- 手：掌・親指の付け根・四指を別の形として作る。原本に指骨がない場合も骨は増やさず、ゲームの構えで拳の輪郭が読める形を選ぶ。
- 装甲は硬質部として対応骨に追従させ、柔軟な接続部だけにウェイトを滑らかに配る。関節を球で置き換えず、深く曲げたときに露出する内側も作る。

## 合格の順番

細部を作る際は次の特徴を三面図と照合する。

| 部位 | 面と境界の見え方 |
| --- | --- |
| 頭 | 正面は中央の銀色マスクの左右に細い黒い切り返し。真横はそこから後ろへ湾曲する側頭部装甲。顎を尖らせ直したり、後頭部に突起を足したりしない。 |
| 胸・肩・背 | 胸骨の中央で左右の面の向きが変わり、胸板の下縁が黒い腹板にかぶる。肩殻の下に暗い可動部が見える。背面では肩甲骨側の左右の面が腰側に収束する。 |
| 腹・骨盤 | 黒い腹部を一様な筒にせず、中央の腹板と脇の屈曲部を分ける。左右の銀の腰板と前中央の装甲の間から股関節が見える。 |
| 四肢・手足 | 膝は黒い受けの上に盾形の板、すねは前面に稜線。肘・膝の裏には曲がる余地を残す。手甲と指節、足首と甲・つま先が一つの塊に見えないこと。 |

**ポリゴン配分:** 面を足す第一の理由は、参照図にある形を出すこと。既存の丸い断面を一律に細分化するより、装甲の縁・段差・断面の向きが変わる位置に頂点を置く。額、肩、大腿などの長い外周は、ゲーム画面の大きさで角が見えない分割を残す。見えない内装から削る場合も屈曲時に露出しないか確認する。26,908三角形は現状の比較値で、達成目標でも固定上限でもない。

正面・側面・背面は同一姿勢・同一縮尺で照合し、装甲の厚みと重なりは斜めからも確認する。無地で判別できない段差を黒線で代用しない。一方、輪郭に影響しない細い継ぎ目はテクスチャでよい。銀のハイライトは視点とともに動き、黒い内装は同じ強さで光らないこと。

1. 実骨格上に胸郭・骨盤・四肢の体積を作る。正面と側面を同一縮尺で参照図に重ね、無地・無光沢でも体格が一致するまで装甲線や材質を作らない。
2. 既存の待機・パンチ・蹴りの最大屈曲で静止し、肩が胴に埋まらない、肘膝が潰れない、装甲の隙間から背景が抜けないことを前後から見る。
3. 銀の外殻と暗い内装を分け、UV上にハイライトや落ち影を焼き込まない。ゲーム側が実際に読める材質とテクスチャで確認する。
4. 新規 Player_01.fbx を再インポートし、既存アニメーション無変更で比較。最後にタイトル原画と同じ構え・カメラで並べる。DCC内の静止画だけで完成扱いしない。
