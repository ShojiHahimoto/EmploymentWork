# タイトル画面の素材

採用するのは最初の白・青緑・黒を基調とする案。赤・黄色を加えた案は採用しない。

## 新規素材

- `../Parts/title_logo_temporary.png`: 仮タイトル「BUILD A BATTLE」と青緑の斜線。透過PNG。縦横比を維持して使用し、9スライスや縦横別の引き伸ばしはしない。
- `../Parts/battle_fists.png`: バトルスタート用の白い拳アイコン。ボタン背景・文字は含めない。透過PNG。
- `../Parts/title_assets.json`: 今回の素材一覧。既存の実行時マニフェストにはまだ登録しない。

## 再利用

- `button_primary.png`: バトルスタートの青緑背景。
- `button.png`: カスタマイズの白い背景。
- `pencil.png`: カスタマイズの鉛筆アイコン。
- 「バトルスタート」「カスタマイズ」は既存の日本語フォントで動的に描画する。
- 背景グリッドと中央キャラクターは3D描画し、背景の一枚絵としては書き出さない。周回カメラとモーション再生を後で実装するため。

今回は素材のみで、タイトルシーンやゲームの挙動は変更していない。

## 生成記録

内蔵imagegenを使用。ロゴは採用画像を参照して、同じ黒の太い斜体・青緑の斜線・透過背景・追加装飾なしを指定。拳は白単色・透明背景・発光なし・文字とボタン背景なしを指定。
