## 採用基準

2026-11-09: ユーザー指定により最初の生成画像を基準に採用。2枚目の修正版ではない。
承認済み編集画面の完全再現を最終目標とする。これらは原稿であり、そのまま完成済みランタイム素材とは扱わない。

- ui_parts_base_v1.png: 最初の生成画像を無加工で保存。4列4行。
- ui_parts_extra_v1.png: 不足素材の追加原稿。4列3行。
- いずれも1536x1024、アルファ付きPNG。隅はalpha=0。中央は基本シートが0、追加シートが4で、追加原稿には微小な半透明成分が残る。実用素材化時に余白のアルファ処理を確認する。
- 透明画素のRGBにも色があるため、RGBのみの表示で見える背景をゲーム背景として使用しない。合成時にはアルファを適用する。

## 基本シート（左から右、上から下）

1. パネル、通常ボタン、強調ボタン、上下矢印付き数値欄
2. チェック無効、チェック有効、補助ラベル背景、現在位置ハンドル
3. 戻る、循環矢印、再生、一時停止
4. 前フレーム、次フレーム、カメラ、キーの菱形

## 追加シート

1. 鉛筆、上矢印、下矢印、モーション編集
2. 見出しアクセント、ヘッダー斜線、ヘッダー背景、再生操作パネル
3. 前隙・持続・後隙の区間背景、短い三角付き現在位置ハンドル

## 目視確認と残作業

- 白・青緑・グレーの基本テイストと必要な記号を確認。
- 追加シートのアイコンにボタン背景が付いたため、入力欄内などに使う際は記号だけを分離する必要がある。
- 角丸・枠幅・縦横比は承認画面と完全一致していない。切り出し、寸法調整、9スライス境界の定義は未実施。
- 区間背景は隣接区間の内側を丸めず接続する必要がある。
- 現在位置線、文字、数値、目盛りは動的描画。画像に含まれる長いハンドル線は使用しない。
- ランタイム接続と画面差分検証は未実施。ゲームのソース・攻撃データ・モーションは今回変更しない。

## 生成方法と指示

内蔵image_genを使用。追加生成の指示要旨: 最初の素材シートに合わせた白・青緑のUI、不足する鉛筆・上下矢印・走る人物・見出し棒・斜線・ヘッダー・再生パネル・3色区間・現在位置ハンドルを4列3行に配置。文字・数字なし、透明背景、細い枠、控えめな陰影。

- ui_geometry_v2_proof.png: 白背景の確認用修正原稿。内蔵image_genで作成。ゲーム用透過素材ではない。

- 白背景原稿で接続面と棒の形状修正を目視確認。ただし外端の角丸量、斜線の幅、微細な色むらは元の承認画面と完全一致していない。最終寸法での調整が必要。
