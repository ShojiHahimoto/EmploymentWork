# カスタマイズ入口 UI素材

## 第2段階

- button_normal.png: 通常時の白系背景。
- button_selected.png: 選択時の青緑背景。
- 各ボタンは文字を含まない透過PNG。文字はNoto Sans JP Boldで動的描画する。
- 内蔵image_genで生成。通常は「白銀の横長角丸、細い灰色枠、控えめな影、文字・記号・スリットなし」、選択は通常画像を参照し「同形状で面のみ青緑」と指定。
- ヘッダーは既存header、斜線はheader_accent、戻るは既存buttonとbackを再利用する。フォントも既存のRegular/Boldを使う。
- 背景は白系の単色とし、新しい背景画像は不要。右側のモデル画像はユーザー指示により今回作成しない。

## 接続時の注意

- 今回は素材準備まで。既存画面の描画・入力・素材一覧は変更しない。
- 新ボタンは旧button_primaryのスリット模様を含まない別ファイル。既存画面へ影響させない。
- 元画像は余白込み2172x724。透明余白を含むため、可視ボタン範囲を操作矩形と合わせる。通常と選択で操作矩形を変えない。
- 9スライスの境界は接続時に可視輪郭と透明余白から確認し、数値を推測で設定しない。上下の影や枠を伸ばさない。
- フォーカスで通常・選択画像と文字色を切り替える。技作成・キャラクター作成で同じ背景素材を共有する。
- 上部ヘッダー、見出し、戻る、左の2項目だけを配置し、右側は画像の準備まで空けておく。
