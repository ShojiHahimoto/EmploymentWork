# 個別UI素材

tools/ExportUIAssets.ps1で原稿から27点を書き出す。元画像は変更しない。
assets.jsonは各画像の寸法と9スライス固定幅を持つ。順序はleft,top,right,bottom、単位は元画像ピクセル。
9スライスは画像を9ファイルに分ける意味ではなく、描画側でこの幅を用いて分割描画する。現時点では描画側へ未接続。

## 確認事項

- 3色帯は別PNG。赤は左のみ、緑は角丸なし、青紫は右のみ丸める。フレーム境界から描画位置と幅を求めて隙間なく接続する。
- 白背景の原稿から3色帯と縦棒を切り出し、外形をアルファ化。端の白混入を避けるため丸い端付近の色は内側から取得する。
- 9スライス固定幅は初期設定。実表示サイズで角丸・枠幅を承認画像と比較して最終調整する。
- pencil/up/down/motionは背景なしの透過アイコン。入力欄やボタンの背景とは別に重ねて使用する。元の背景付き4画像は廃止。
- header_accentは水平な上下端と淡色・青緑の構成を持つ透過素材。縦横を独立に引き伸ばさず、表示比率は元の承認画面に合わせて調整する。
- tools/TestUIAssets.ps1で全ファイルの寸法・9スライス境界を検査し、inspection.pngへ白背景で実合成した一覧を出力する。この一覧はゲーム素材として読み込まない。
- number_fieldは上下矢印込み。up/downを重ねて二重描画しない。記号を別配置する際は通常の白背景素材を使用する。
- 各画像の切り出しと透明合成の確認まで実施。実表示サイズでの枠幅・角丸の最終調整は、9スライス実装後に参考画面と比較する。
- 素材分割までの段階。専用UIへの接続、9スライス描画実装、全画面の一致確認は未実施。
