# タイトル画面素材 第2案

作成日: 2026-11-10

## 素材

- `title_logo.png`: BUILD A BATTLEの仮ロゴ。黒い斜体文字、中央の青緑の斜線、下線とコーラル色のアクセント。
- `button_normal.png`: 未選択の白系ボタン背景。文字なし。
- `button_selected.png`: 選択中の青緑ボタン背景。文字なし。
- 全て2172 x 724、32bit RGBA PNG。外周の透明ピクセルを確認済み。面部分のアルファは主に253/255で、完全不透明ではない。

旧素材は変更していない。2026-11-13の第2段階で実行時のassets.jsonへtitle_v2_logo / title_v2_normal / title_v2_selectedとして登録した。このフォルダはタイトル画面完成形イメージ2を基準とする新版。キャラクターとグリッド部屋は既存の3D描画を使うため画像化しない。

## 次工程の描画

- ロゴは縦横比を維持。透明余白を含む画像全体の矩形と実際の可視部分を混同しない。
- ボタンもまず縦横比を維持して描画する。可視ボタンは横長で約5:1。画像全体は余白込みで3:1なので、レイアウトのボタン高さへ画像全体を無条件に伸縮しない。
- 斜めの輪郭・装飾を含むため、通常の9スライスで上下左右を独立に伸ばす方法は採用しない。画面比率に応じた一様スケールを基本とする。
- 通常・選択の背景は両メニューで共有。文字は別描画し、通常は黒、選択中は白とする。
- 2状態の生成画像には微小な輪郭差がある。第2段階では可視範囲を合わせ、入力矩形は状態にかかわらず固定し、切替でレイアウトを動かさない。
- ボタン中央の文字領域には斜線装飾を重ねない。画像の透明な余白をヒット領域として広く取りすぎない。
- 外周透過・文字のない背景・構図をファイルで確認済み。ゲーム画面への適用、背景上でのエッジ、選択切替の実機確認は第2段階で行う。

## 生成記録

内蔵image_genを使用。参照: `タイトル画面完成形イメージ2.png`。

ロゴ用プロンプト: 参照画像からBUILD A BATTLEのロゴだけを透過素材として再現。黒い太い斜体、中央の青緑の稲妻状斜線、青緑の下線、コーラル色のアクセントを維持。背景・人物・ボタンは含めない。

通常ボタン用プロンプト: 参照画像右下の白い斜めボタン背景のみ。文字なし、白から淡い銀色の面、細い灰色の外枠と白い内枠、控えめな影、右端の青緑の斜線。外周透過。ガイド線やグリッドは入れない。

選択ボタン用プロンプト: 通常ボタン画像を形状参照、完成形画像を色参照として、同じキャンバス・配置・輪郭を維持し、面を青緑に変更。装飾は左端の明るい青緑斜線。文字なし、外周透過。

生成元はCodex generated_imagesに保存された原本を残し、本フォルダへコピーした。実行コードの変更・既存素材の上書きは行っていない。
